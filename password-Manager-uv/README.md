# Personal Library Manager

A simple streamlit application to manage a personal library of books.made by uv and deployed on streamlit

## Features

- Add new books to the library
- Delete books from the library
- Search for books in the library
- Update book information
- Show all books in the library
- Show reading progress

## Technologies Used

- Python
- JSON file for data storage
- UV


## Usage

Run the application by executing the `main.py` file.

```bash
uv init password-Manager-uv
```
```bash
cd password-Manager-uv
```
```bash
uv add streamlit
```
```bash
.venv/Scripts/activate
```
```bash
 uv run streamlit password-Manager.py

```
Follow the instructions inside the terminal to manage your library.

That's it! You can now manage your library using the command
-on streamlit
